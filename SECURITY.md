# Security Policy

## Sensitive information

This repository is intentionally sanitized. Do not open an issue or pull request containing credentials, private keys, patient/customer information, real firewall exports, or other secrets.

If you discover that sensitive information has accidentally been committed, remove it from public access immediately, rotate any exposed credential/key, and rewrite repository history as appropriate. Deleting only the latest version of a file is not sufficient if the secret remains in Git history.

## Scope

This repository is a portfolio/documentation project and is not a supported security product.
