# Screenshot Guide

Add only sanitized screenshots.

Recommended evidence:

- `dashboard/` — pfSense dashboard with system/interface/security widgets
- `firewall-rules/` — LAN/DNS policy rules with identifying values removed
- `pfblockerng/` — DNSBL/IP/GeoIP status and safe test results
- `snort/` — LAN/WAN interfaces, enabled rules, and controlled test alerts

Before committing, inspect every screenshot for public IPs, names, email addresses, hostnames, MAC addresses, browser tabs, credentials, API keys, customer/patient information, and QR codes.
